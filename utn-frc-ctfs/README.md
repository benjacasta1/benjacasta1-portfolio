# UTN-FRC CTFs

Repositorio de prácticas y writeups de desafíos de ciberseguridad realizados en el marco de actividades de la **UTN-FRC** y el **HackLab de Seguridad**.

Los desafíos se desarrollan en entornos controlados y están orientados al análisis de vulnerabilidades, explotación y resolución de problemas de seguridad.

## Objetivos

- Practicar técnicas de reconocimiento y enumeración.
- Analizar vulnerabilidades en aplicaciones y servicios.
- Comprender y explotar fallos de seguridad en entornos controlados.
- Mejorar el uso de herramientas de ciberseguridad.
- Documentar procedimientos y aprendizajes.
- Construir un registro práctico de experiencia en ciberseguridad.

## Áreas trabajadas

- Reconocimiento y enumeración
- Seguridad Web
- SQL Injection
- Autenticación y control de acceso
- Manipulación de parámetros
- Explotación de vulnerabilidades
- Análisis de APIs
- Linux
- Redes
- Análisis de tráfico
- CTFs
